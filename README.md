# saebom-studyhall (주소 넘겨주기 전용)

새봄 면학관 웹은 2026-10-12 부터 **https://saebom-admin.web.app** 에서 운영합니다(소스 저장소는 비공개로 전환).
이 저장소는 옛 GitHub Pages 주소·옛 키오스크/타종 설치본이 계속 동작하도록 남겨 둔 넘겨주기 페이지만 담습니다.
각 페이지는 이 기기의 저장값(기기 등록)을 들고 새 주소로 넘어갑니다. 개인정보·소스 코드는 없습니다.

- `saebom_bell.html` 은 옛 타종 설치본(start-bell.bat)이 raw 주소로 받아 가는 최신본 사본이다.
