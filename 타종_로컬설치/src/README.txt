새봄 면학관 타종 - 윈도우 설치 안내
====================================

이 폴더를 면학관 메인컴(스피커가 물린 컴퓨터)에 두고 씁니다.
인터넷이 끊겨도 종은 계속 울립니다.


[ 설치 - 세 걸음 ]

 1. 이 폴더를 통째로 아래 경로에 둡니다.
    권장:  C:\saebom-bell\
    ( 한글이나 띄어쓰기가 없는 경로가 안전합니다 )

 2. start-bell.bat 을 더블클릭합니다.
    크롬이 주소창 없는 전용 창으로 뜨면 성공입니다.

 3. install-autostart.bat 을 더블클릭합니다.
    이제 컴퓨터를 켜면 타종이 저절로 뜹니다.


[ 켠 다음 확인할 것 ]

 화면 위쪽이 이러면 정상입니다.

   - 시계가 초 단위로 움직인다
   - 빨간 줄이 없다
   - "이 기기에서 소리 남" 이라고 되어 있다
     (아니면 "이 기기에서 소리 내기" 버튼을 눌러 켜세요)
   - "다음 타종 - 월 18:00 7교시 시작" 처럼 다음 종이 표시된다

 그리고 요일과 교시를 표에서 골라 두고, "타종" 버튼을 켜 두세요.


[ 아주 중요 ]

 반드시 start-bell.bat 으로 여세요.

 크롬에 saebom_bell.html 을 그냥 끌어다 놓으면, 컴퓨터를 켤 때마다 사람이
 빨간 "소리가 잠겨 있습니다" 줄을 눌러 줘야 합니다. 안 누르면 종이 안 울립니다.
 start-bell.bat 은 그 클릭이 필요 없게 만드는 옵션을 붙여서 크롬을 띄웁니다.


[ 소리 시험 ]

 - 잠금 해제, 종소리 고르기, 음량 조절을 눌렀을 때 나는 "삑" 소리는
   확인음입니다. 아주 작고 짧아서 면학관까지 들리지 않습니다.
 - 진짜 종소리는 "실제 종소리 듣기" 버튼으로만 납니다. 누르면 지금이 몇 교시
   수업 중인지 알려주고 한 번 더 물어봅니다.


[ 문제가 생기면 ]

 종이 안 울린다
   1) 타종 창이 떠 있는지
   2) 빨간 줄이 있는지 (있으면 누르기)
   3) "이 기기에서 소리 남" 인지
   4) 컴퓨터 볼륨과 스피커 전원

 빨간 줄이 계속 뜬다
   start-bell.bat 으로 열지 않았을 가능성이 큽니다. 창을 닫고 다시 여세요.

 "원격 연결 안 됨" 이라고 뜬다
   인터넷 문제입니다. 종은 정상으로 울립니다.
   휴대폰에서 시간표를 바꾸는 기능만 잠시 안 될 뿐입니다.

 창을 실수로 닫았다
   start-bell.bat 을 다시 실행하세요.


[ 손대면 안 되는 것 ]

 _profile 폴더는 이 타종 창 전용 크롬 프로필입니다.
 지우면 "이 기기에서 소리 냄" 설정이 풀려서 종이 조용히 안 울리게 됩니다.
 실수로 지웠다면 창에서 "이 기기에서 소리 내기" 를 다시 눌러 주세요.


[ 갱신 ]

 start-bell.bat 은 실행할 때마다 최신 타종 페이지를 받아옵니다.
 인터넷이 없으면 컴퓨터에 있던 파일로 그냥 뜹니다.


[ 들어 있는 파일 ]

 start-bell.bat          타종 시작 (평소 쓰는 것)
 install-autostart.bat   부팅할 때 자동 실행 등록
 uninstall-autostart.bat 자동 실행 해제
 saebom_bell.html        타종 페이지 본체
 README.txt              이 파일
