# 면학관 타종 — 메인컴 로컬 설치 (윈도우)

타종 페이지를 **면학관 메인컴에 파일로 두고** 돌립니다. 인터넷이 끊겨도 종은 계속 울립니다.

## 왜 로컬인가

GitHub Pages 주소로 열면, 인터넷이 끊긴 상태에서 브라우저를 다시 켰을 때 **페이지 자체가 안 열려서
종이 통째로 멈춥니다.** 파일로 두면 그 일이 없습니다.

원격 설정(폰에서 시간표 바꾸기)은 인터넷이 될 때만 동작하고, 끊기면 **마지막 설정 그대로** 울립니다.
지금 어느 쪽인지는 화면 위 뱃지가 알려 줍니다 — `☁️ 원격 설정 연결됨` / `⚠️ 원격 연결 안 됨`.

## 설치 (한 번만)

1. 메인컴에 폴더를 하나 만듭니다. **한글·띄어쓰기 없는 경로**를 권합니다.
   ```
   C:\saebom-bell\
   ```
2. 이 폴더의 `타종시작.bat` 을 거기 넣습니다.
3. `타종시작.bat` 을 더블클릭합니다.
   - 페이지 파일(`saebom_bell.html`)은 스크립트가 알아서 내려받습니다.
   - 크롬이 주소창 없는 전용 창으로 뜨면 성공입니다.

## 부팅하면 저절로 뜨게

1. `타종시작.bat` 우클릭 → **바로 가기 만들기**
2. `Win + R` → `shell:startup` → 엔터 (시작프로그램 폴더가 열립니다)
3. 방금 만든 바로 가기를 그 폴더에 넣습니다

이제 컴퓨터를 켜면 타종 창이 저절로 뜨고, **사람이 아무것도 누르지 않아도 소리가 납니다.**

## 켜고 나서 확인할 것

화면 위쪽이 이렇게 보이면 정상입니다.

- 시계가 초 단위로 움직인다
- **빨간 줄이 없다** (있으면 눌러 주세요)
- `🔊 이 기기에서 소리 남` — 이게 `🔇` 면 눌러서 켭니다
- `다음 타종 · 월 18:00 7교시 시작 — 3시간 12분 후` 처럼 다음 종이 표시된다

## 갱신

`타종시작.bat` 은 실행할 때마다 최신 페이지를 내려받습니다. 인터넷이 없으면 있던 파일로 그냥 뜹니다.
받은 파일이 타종 페이지가 맞는지 확인한 뒤에만 덮어쓰므로, 공유기 로그인 화면 같은 게 대신
내려와도 멀쩡한 파일이 깨지지 않습니다.

## 문제 해결

| 증상 | 확인 |
|---|---|
| 종이 안 울린다 | 타종 창이 떠 있나 → 빨간 줄이 있나 → `🔊` 인가 → 컴퓨터 볼륨·스피커 전원 |
| 빨간 줄이 계속 뜬다 | `타종시작.bat` 으로 켰나? 크롬을 그냥 열어 파일을 끌어다 놓으면 자동재생 옵션이 안 붙습니다 |
| `⚠️ 원격 연결 안 됨` | 인터넷 문제입니다. **종은 정상으로 울립니다** — 폰에서 시간표를 못 바꿀 뿐입니다 |
| 창을 실수로 닫았다 | `타종시작.bat` 다시 실행 |

## 손대면 안 되는 것

`_profile` 폴더는 이 타종 창 전용 크롬 프로필입니다. 지우면 **"이 기기에서 소리 냄" 설정이 초기화**돼
스피커 지정이 풀립니다. 지웠다면 창에서 `🔇 이 기기에서 소리 내기`를 다시 눌러 주세요.
