# 면학관 타종 — 윈도우 설치

**받는 곳:** https://doctorj011-blip.github.io/saebom-studyhall/saebom-bell-setup.zip

압축을 풀고 `README.txt` 를 읽으면 됩니다. 세 걸음입니다.

1. 폴더째 `C:\saebom-bell\` 에 둔다
2. `start-bell.bat` 더블클릭
3. `install-autostart.bat` 더블클릭 (부팅 자동실행)

---

## 이 폴더 구성

| | |
|---|---|
| `src/` | 설치 파일 원본. **여기를 고친다** (UTF-8) |
| `build.py` | `src/` 를 윈도우 인코딩으로 바꿔 저장소 루트에 `saebom-bell-setup.zip` 을 만든다 |

`src/` 를 고쳤으면 반드시 `python3 build.py` 를 돌려 zip 을 다시 만들고 함께 커밋할 것.
**zip 은 빌드 산출물이라 자동으로 갱신되지 않는다.**

## 왜 인코딩을 변환하는가

한국어 윈도우 콘솔 기본 코드페이지는 **949**다. `.bat` 을 UTF-8 로 두면 한글이 깨진다.
`chcp 65001` 로 바꾸는 방법도 있지만, UTF-8 배치는 파서가 첫 줄부터 어긋나는 사고가 알려져 있어
아예 CP949 로 저장하는 쪽이 안전하다. `build.py` 가 이걸 한다.

- `.bat` → **CP949 + CRLF**. CP949 에 없는 문자(이모지·✅ 등)를 쓰면 빌드가 실패한다 — 의도한 것이다.
- `.txt` → **UTF-8 BOM + CRLF**. 메모장이 BOM 없는 UTF-8 을 옛 윈도우에서 CP949 로 잘못 읽는다.
- 압축 안 파일 이름은 전부 **ASCII**. 한글 이름은 탐색기 버전에 따라 깨져 보이고,
  배치들이 서로를 이름으로 부르기 때문에 위험을 없앴다.
- **`powershell -Command` 인자 안에 한글을 넣지 말 것.** 콘솔 코드페이지를 타서 깨진다.
  사람에게 보여줄 한글은 배치의 `echo` 로 낸다.

## 핵심 옵션 (건드리면 안 되는 것)

`start-bell.bat` 이 크롬에 주는 두 옵션이 이 설치의 전부다.

- `--autoplay-policy=no-user-gesture-required`
  사람이 클릭하지 않아도 소리가 난다. 없으면 켤 때마다 빨간 잠김 줄을 눌러 줘야 한다.
- `--user-data-dir=...`
  업무용 크롬과 프로필 분리. **이걸 빼면 위 옵션이 통째로 무시된다** — 크롬이 이미 떠 있으면
  새 프로세스가 아니라 기존 크롬에 탭만 하나 더 열리기 때문이다.
